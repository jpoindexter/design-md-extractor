Constraints

  • No new runtime dependencies (port the store-zip to Node).
  • Evidence public shape stays compatible (new fields optional); collection stays serializable.
  • Re-ranking intentionally changes token names/values → update those tests; canvas stays right via surfaces[0].

Not in this round — missing capabilities

This plan makes what the extractor does correct and complete. It does not add things the extractor never attempts — those are net-new features (real value for rebuild fidelity, but not fixes), a separate larger track.
  • Interaction states — hover / focus / active / disabled. Reads static computed styles only; never triggers interactions → a rebuild has no state info.
  • Gradients — the colour collector reads solid backgroundColor only; background-image: linear-gradient() is ignored.
  • Motion — transitions, animations, durations, easings: not captured.
  • Imagery & icons — "Imagery strategy: unknown" every run; no icon / illustration / photo detection.
  • Component classification quality — dedupes components but doesn't fix the shallow card/button/badge heuristic (over-labeled 30+ "Cards" on monarque).
  • Crawl robustness — page discovery, JS-heavy SPAs, lazy-loaded / late-settling content, infinite scroll (isomeet yielded only 1 page).
